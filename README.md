One word for your Wi-Fi: **Liar**. Full signal bars, "Connected, no internet", and nothing loads — the network claims to be connected while delivering nothing. It is an accusation aimed at the router, funny at once and instantly recognisable to anyone who has stared at full bars while a page refuses to load. The program writes that single word to `entry.txt`, self-checking the one-word, no-whitespace, 20-character rules first.

## Run it

```sh
python3 main.py
```

This writes `Liar` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is not set).
